גאון החשבון - משחק חשבון בעברית

פתיחה: חלצו את כל הקבצים מה-ZIP ופתחו את index.html בדפדפן.
השאירו את icon.png באותה תיקייה עם index.html.

ארבע רמות: מתנסים 4-6, מתחילים 6-8, מתקדמים 8-10, מנוסים 10-19.
שמונה עולמות, שלושים שלבים בכל עולם, שישה בתים בכל עולם.
המשחק פועל ללא חיבור לאינטרנט לאחר חילוץ הקבצים.
ההתקדמות נשמרת באחסון המקומי של הדפדפן; ניקוי נתוני האתר עשוי למחוק אותה.
